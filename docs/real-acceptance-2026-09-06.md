## 本轮修复与回归证据

1. 图片/PDF 正文漏读：保留 AXImage、AXPage 类型；大块图片/页面缺乏可定位正文时进入 OCR；图片中的 Live Text 坐标不可信时也回退。小图标不触发 OCR，有合法 Live Text 的大图仍使用 AX。对应测试先失败后通过。
2. 本地输出合同：真实模型在 json_object 模式输出裸数组。改用 JSON Schema，并限制数量与区域 ID，保留客户端完整校验；增加明确复制 ID 的提示。真实生产接口连续 10 次通过。
3. 本地启动误读云端密钥：启动本地模式不再读取云端 Keychain；用户明确切换云端时才读取。回归测试从 readCount=1 失败变为 0 通过。
4. 过期请求排队：取消显示任务原先没有取消 URLSession 请求，拖慢单并发本地服务；现在取消传递到底层请求，并处理取消先于请求启动的时序。延迟网络协议测试先失败、修复后约 109 ms 通过。
5. 退出计时器：事件循环返回后立即停掉轮询计时器，避免等待启动任务完成期间重复 stop。
6. 控制 socket 偶发断连：macOS 接受的 socket 继承非阻塞模式，稍后发送请求会被当作读失败断开。延迟 50 ms 发送的测试稳定得到 sent=-1、received=0；清除接受连接的 O_NONBLOCK 后通过。
7. 退出遗留 PID：界面退出通知早于 PID 清理，可能使进程提前退出。新增检查通知时 PID/socket 已不存在的测试，先失败后通过；现在完成清理后才发送界面退出通知。

最后完整验证：`swift test -Xswiftc -strict-concurrency=complete`，163 tests / 16 suites 通过。Release 严格并发构建通过。此前测试中出现的退出次数和控制 socket 时序失败已分别定位并修复；没有删除或放宽原失败断言。

## 当前阻塞和剩余风险

- 桌面持续存在 global-translator 的遗留钥匙串密码框，以及另一项 Blender 文稿权限弹窗。已停止触发前者的 doctor 进程，但系统对话框仍在。Computer Use 明确禁止操作 SecurityAgent；未代填密码、修改权限或干预 Blender 任务。已请求用户人工关闭/处理，尚未收到完成反馈。
- 弹窗遮挡条件下，没有把后台 AX 点击当成真实鼠标穿透，也没有宣称拖动、缩放、全屏、普通输入与密码输入的完整交互通过。
- PNG 在同 App 窗口切换后仍发生捕获失败；Finder 的持续变化事件和 Cursor 的正文覆盖层需要在干净、可交互的桌面继续定位。
- 本机单句中位数约 1.60 秒，整窗批次可达约 9–11 秒；性能目标未全部达到。
- 裸可执行文件菜单栏项目可能被系统裁切的既有限制仍适用，见 [架构记录](decisions/001-bare-executable-status-item.md)。
