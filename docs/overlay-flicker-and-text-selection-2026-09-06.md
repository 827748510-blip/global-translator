# 译文闪烁与文字筛选修复

分支：codex/fix-overlay-flicker，基于 main 9d244ba。本轮未提交或推送。

## 问题与修改

- 原画面变化回调将像素变化直接标为译文失效；值/标题通知也可能导致整层清空。现先复查实际文字，窗口切换、明确几何变化和保护状态仍立即隐藏。
- 复查后复用仍然有效的译文及气泡 ID；只有部分文字变化时保留其他气泡，滚动后已知文字直接重新定位。相同内容不重绘，不为相同位置重复设置面板 frame/顺序。
- 修复英文句子中包含 URL/路径就被整句过滤的问题；纯 URL/路径仍跳过。
- 增加本机语言识别及中文混排缩写处理；对代码标识符、版本/单位值等非自然语言进行过滤。保留 Open/SAVE 等短操作标签、英文正文和繁体转简体。
- AX 优先给可读正文分配名额；OCR 在截取最多24个区域前优先选择需要翻译的文字，避免中文和数字先占满名额。
