# 截图翻译（区域 OCR）

按可自定义快捷键，拖选屏幕区域，用 **本机 Apple Vision** 识别中/英文，再走与滑词翻译相同的本地 Ollama / DeepSeek 后端，在浮窗里显示原文和译文。识别出 **英文 / 其他外文** 译成简体中文；识别出 **简体中文** 则译成英文（与滑词翻译同一套双向互译）。

**不走云端 OCR，不向任何云端或本地大模型上传原始截图。** 截图默认不保存、不上传。**「保存截图」开关开启时**才会按原子安全权限把拖选区域写成 PNG 到本机目录（见下）；默认关闭。

## 启用

1. 将应用安装到 `~/Applications/Global Translator.app`（或 `/Applications/Global Translator.app`）并启动。
2. 在设置里授权 **屏幕录制**（与窗口覆盖层 / 变化检测同一项）。未授权时按快捷键会提示「截图翻译需要屏幕录制权限，请到设置授权」，并走现有「授权 / 打开系统设置」入口。
3. 配置翻译后端（本地 Ollama 或 DeepSeek API Key），与滑词翻译相同。本地需填回环地址并选择模型；云端需 Key。
4. 默认快捷键 **⌃⇧T**（Control+Shift+T）。可在设置「截图翻译」里点 **录制** 改成其他带 ⌃ / ⌥ / ⌘ 的组合。与系统截图 ⌘⇧3/4/5 冲突时会红字提示。
5. **自动复制译文** 默认关闭。打开后，翻译成功会把译文写入剪贴板；仍可用浮窗「拷贝」按钮手动复制。

## 保存 / 复制截图（新）

- **保存截图**（默认关）：翻译完成后把拖选区域存成 PNG。文件名形如 `截图翻译-YYYYMMDD-HHMMSS-xxxx.png`。
- **复制截图**（默认关）：翻译完成后把拖选区域图片复制到剪贴板（PNG），可直接粘贴到聊天 / 文档。
- **保存位置**：设置里显示当前目录（`~` 缩写），点 **选择…** 可换；默认是 `~/Pictures/Global Translator 截图`，不存在时自动创建。
- 保存成功后，浮窗在译文下方显示 **已保存到 <路径>**（可选中复制）。保存失败只记日志，不阻断翻译，浮窗正常显示译文。
- 保存 / 复制发生在 OCR 之前：即使识别不到文字或翻译失败，你要的截图也已经按开关保留。

## 行为

1. 快捷键弹出全屏半透明遮罩（不激活其它 App 之外的额外抢焦点），拖选矩形；Esc 取消（不弹浮窗）。
2. 拖完但区域过小、OCR 无字、识别失败、翻译失败都会在浮窗里给出中文说明，不会静默失败。过小区域用「未选中有效区域」。文案精神与滑词翻译失败一致（例如缺 DeepSeek Key 时是「请到设置填写 DeepSeek API Key 并测试连接」）。
3. 识别文本交给现有 `TranslationSession.translateSelection`，后端由设置页「翻译后端」决定；方向自动判定（中文→英文，其余→简体中文）。
4. 浮窗支持 **SSE 流式显示译文**，识别出文本后左侧提供 **复制原文** 按钮，右侧提供 **复制译文** 按钮（未识别出文字时保持常规关闭/拷贝交互）。不做「改 OCR 再译」、不做历史、不做全屏一键截图。

## 本机验证（macOS）

1. 打开 `~/Applications/Global Translator.app`（或 `/Applications/Global Translator.app`），设置里屏幕录制为「已授权」。
2. 后端选 **本地模型**，Ollama 已启动并测试连接；或 DeepSeek 已保存 Key。
3. 按 ⌃⇧T，拖选一段英文，应弹出原文 + 简体中文，点「拷贝」应变为「已拷贝」。系统剪贴板在自动复制关闭时应仍是你原来的内容，直到点拷贝。
4. 打开「自动复制译文」后再截一次，剪贴板应为译文。关掉该开关后不应再自动写入。
5. 拖选一段**中文**：应弹出原文 + **英文**译文（双向互译）。
6. 打开「保存截图」，截一段：设置里「保存位置」显示的目录里应出现 `截图翻译-….png`，浮窗译文下方应显示「已保存到 <路径>」。
7. 打开「复制截图」，截一段：剪贴板应变成 PNG 图片（可粘贴到备忘录/聊天验证）。关掉后剪贴板不再被截图覆盖。
8. 拖一个几乎没有像素的区域：应看到「未选中有效区域」。空白区域：应看到「未识别到文字」。
9. 关掉屏幕录制权限后再按快捷键：应看到权限说明，而不是空白。
10. 设置里录制一个已被占用或与系统截图冲突的组合：应看到明确冲突文案。
11. `swift test -Xswiftc -warnings-as-errors`（仅 macOS；Linux 无 AppKit / Vision / ScreenCaptureKit）。
