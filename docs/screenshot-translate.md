# 截图翻译（区域 OCR）

按可自定义快捷键，拖选屏幕区域，用 **本机 Apple Vision** 识别中/英文，再走与滑词翻译相同的本地 Ollama / DeepSeek 后端，在浮窗里显示原文和简体中文译文。

**不走云端 OCR，不调用公司 openapi。** 截图不保存、不上传（除非你另外开启了「视觉兜底」，那是另一条 DeepSeek 截图路径，与本功能无关）。

## 启用

1. 将应用安装到 `/Applications/Global Translator.app` 并启动。
2. 在设置里授权 **屏幕录制**（与窗口覆盖层 / 变化检测同一项）。未授权时按快捷键会提示「截图翻译需要屏幕录制权限，请到设置授权」，并走现有「授权 / 打开系统设置」入口。
3. 配置翻译后端（本地 Ollama 或 DeepSeek API Key），与滑词翻译相同。本地需填回环地址并选择模型；云端需 Key。
4. 默认快捷键 **⌃⇧T**（Control+Shift+T）。可在设置「截图翻译」里点 **录制** 改成其他带 ⌃ / ⌥ / ⌘ 的组合。与系统截图 ⌘⇧3/4/5 冲突时会红字提示。
5. **自动复制译文** 默认关闭。打开后，翻译成功会把简体中文写入剪贴板；仍可用浮窗「拷贝」按钮手动复制。

## 行为

1. 快捷键弹出全屏半透明遮罩（不激活其它 App 之外的额外抢焦点），拖选矩形；Esc 取消。
2. 区域过小、OCR 无字、识别失败、翻译失败都会在浮窗里给出中文说明，不会静默失败。文案精神与滑词翻译失败一致（例如缺 DeepSeek Key 时是「请到设置填写 DeepSeek API Key 并测试连接」）。
3. 识别文本交给现有 `TranslationSession.translateSelection`，后端由设置页「翻译后端」决定。
4. 浮窗显示 OCR 原文 + 译文，提供拷贝。不做「改 OCR 再译」、不做历史、不做全屏一键截图。

## 本机验证（macOS）

1. 打开 `/Applications/Global Translator.app`，设置里屏幕录制为「已授权」。
2. 后端选 **本地模型**，Ollama 已启动并测试连接；或 DeepSeek 已保存 Key。
3. 按 ⌃⇧T，拖选一段英文，应弹出原文 + 简体中文，点「拷贝」应变为「已拷贝」。系统剪贴板在自动复制关闭时应仍是你原来的内容，直到点拷贝。
4. 打开「自动复制译文」后再截一次，剪贴板应为译文。关掉该开关后不应再自动写入。
5. 拖一个几乎没有像素的区域：应看到「未选中有效区域」。空白区域：应看到「未识别到文字」。
6. 关掉屏幕录制权限后再按快捷键：应看到权限说明，而不是空白。
7. 设置里录制一个已被占用或与系统截图冲突的组合：应看到明确冲突文案。
8. `swift test -Xswiftc -warnings-as-errors`（仅 macOS；Linux 无 AppKit / Vision / ScreenCaptureKit）。
