# 滑词翻译

在任意 App 里用鼠标划选文字，松手后在选区附近弹出简体中文译文，并可一键 **优化提示词**。与窗口覆盖层气泡、Chrome 扩展桥相互独立。

## 行为

1. 菜单栏设置里有 **滑词翻译** 开关，默认开启。关闭后不再监听划选、不弹层，优化提示词也不可用。
2. 仅在 **鼠标左键抬起** 且选区稳定约 150ms 后读取选区；拖拽过程中不弹层。
3. 弹层展示截断后的原文、结果，以及 **翻译** / **优化提示词** / **拷贝**。划选后默认先翻译；点「优化提示词」才改写草稿。Escape、点击外部、或选区变空时关闭。关掉后同一选区不会立刻再弹；选区清空或换成别的句子后才会再出。
4. 目标语言沿用应用现有设置（当前固定简体中文）。已是简体中文时不请求翻译，显示「已是中文」，但 **仍可优化提示词**（中文草稿很常见）。
5. 空选区、纯空白、单击未划选、以及 `TextFilter` 会拒绝的标识符 / 纯 URL 等不弹层。划选后若读不到文字，短暂显示「无法读取所选文字」（约 1.5 秒后自动收起）；Escape、点击外部、选区变空或再次按下会立刻关闭。
6. 翻译和优化都走现有后端：已配置本地 Ollama 则用本地（同一 `SerializingTranslationBackend` 串行槽），否则 DeepSeek。不会静默换到别的云厂商。优化使用独立的 `completePlain` 提示词，不走翻译 JSON schema，也不取消 overlay/bridge 在途请求。
7. 优化目标是 **通用生成提示词**（主体、风格、构图、光线、约束等），不是即梦 / 可灵等厂商专用格式。默认输出简体中文，专有名词保留；明显的纯英文草稿可保持英文。
8. 不依赖「自动翻译」开关，也不依赖窗口覆盖层是否在跑。Chrome 因扩展桥跳过 overlay 时，滑词仍然可用。

## 权限与选区读取

需要 **辅助功能**（与现有 AX 采集相同）。未授权时只记日志，不弹层、不崩溃。单击空白处不会弹出「无法读取所选文字」。划选后某个 App 读不到文字时，弹层短暂显示该提示后自动收起。

默认用 AX `kAXSelectedText` / 焦点元素的选区范围。剪贴板兜底只在能 **完整备份** 当前剪贴板时才会发 ⌘C，读完 **立刻恢复**；承诺文件 / 延迟数据等无法完整备份时跳过 ⌘C，避免毁掉用户剪贴板。密码框（SecureTextField）以及系统安全输入开启时不读、也不走剪贴板。本应用自己的窗口始终跳过（不弹层、拖选后也不发 ⌘C）。

### 飞书 / Electron 类 App

飞书、Lark 以及不少 Electron / 自绘文本的 App **不暴露可用的 AX `selectedText`**，选区范围也经常是 0。旧逻辑只在「AX 报告 range.length > 0 却给不出字符串」时才 ⌘C，这类 App 永远走不到兜底，划选后静默无弹层。

现在的规则：

1. **鼠标拖选后松手**（按下期间收到 `leftMouseDragged`，系统本身会滤掉几乎不动的位移）：AX 若是 `.empty` / `.unavailable` 且没有可用字符串，才尝试 ⌘C 剪贴板兜底。读到的文本与普通选区一样走 `TextFilter.selectionDecision`（中文显示「已是中文」+ 优化提示词；外文翻译；标识符 / URL 跳过），来源标记为 `clipboardFallback`。
2. **单击、无拖拽**（或可忽略的位移）：不发 ⌘C、不弹层，避免点一下就出现红字或改剪贴板。
3. 拖选后剪贴板也读不到字：短暂显示「无法读取所选文字」，约 1.5 秒后自动收起。
4. 本机窗口、密码框、剪贴板无法完整备份：跳过 ⌘C。

风险：⌘C 会短暂占用通用剪贴板；若目标 App 的拷贝快捷键绑定的不是当前视觉选区，可能读到别的内容。备份/恢复失败时宁可不弹层，也不留下用户剪贴板被换成选区文本。

## 本机验证（macOS）

1. 授予辅助功能后打开 Global Translator，确认设置里「滑词翻译」为开。
2. 配置本地 Ollama 或 DeepSeek（与自动翻译同一套后端）。
3. 在 **TextEdit / 备忘录** 中划选一句英文，松手后应在选区附近看到中文、**翻译**、**优化提示词**和拷贝。单击空白处不应弹层。
4. 点 **优化提示词**，应变为优化中，然后出现改写后的通用提示词，可拷贝。
5. 划选一句中文草稿（例如「一个女孩站在雨里」）：应显示「已是中文」，不请求翻译；点优化提示词仍应产出更完整的提示词。
6. 在 **飞书 / Lark** 聊天气泡里拖选中文或外文：应弹出滑词层（中文「已是中文」+ 优化提示词，外文则翻译）。仅单击气泡、不拖选，不应出现弹层，也不应改掉系统剪贴板里原来的内容。
7. 划选后看系统剪贴板：应仍是划选前的内容（⌘C 只是瞬间借用）。
8. 关闭「滑词翻译」后再划选，不应再出现弹层。
9. 打开 Chrome 且自动翻译 + 扩展桥开启时，页面不应出现 overlay 气泡，但划选仍应弹出滑词译文 / 优化。
10. `swift test -Xswiftc -warnings-as-errors`
