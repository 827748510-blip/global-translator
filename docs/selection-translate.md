# 滑词翻译

在任意 App 里用鼠标划选文字，松手后在选区附近弹出简体中文译文。与窗口覆盖层气泡、Chrome 扩展桥相互独立。

## 行为

1. 菜单栏设置里有 **滑词翻译** 开关，默认开启。关闭后不再监听划选、不弹层。
2. 仅在 **鼠标左键抬起** 且选区稳定约 150ms 后读取选区；拖拽过程中不弹层。
3. 弹层展示截断后的原文、译文和 **拷贝**。Escape、点击外部、或选区变空时关闭。关掉后同一选区不会立刻再弹；选区清空或换成别的句子后才会再出。
4. 目标语言沿用应用现有设置（当前固定简体中文）。已是简体中文时不请求模型，短暂显示「已是中文」。
5. 空选区、纯空白、以及 `TextFilter` 会拒绝的标识符 / 纯 URL 等不弹层。
6. 翻译走现有后端：已配置本地 Ollama 则用本地（同一 `SerializingTranslationBackend` 串行槽），否则 DeepSeek。不会静默换到别的云厂商。
7. 不依赖「自动翻译」开关，也不依赖窗口覆盖层是否在跑。Chrome 因扩展桥跳过 overlay 时，滑词仍然可用。

## 权限

需要 **辅助功能**（与现有 AX 采集相同）。未授权时只记日志，不弹层、不崩溃。某个 App 读不到 `selectedText` 时，弹层显示一行「无法读取所选文字」。

默认用 AX `kAXSelectedText` / 焦点元素的选区范围。仅当 AX 报告选区长度大于 0 却给不出字符串、且当前剪贴板能完整备份时，才临时 ⌘C 读取剪贴板，并 **立刻恢复** 原内容。承诺文件 / 延迟数据等无法完整备份时跳过 ⌘C，避免毁掉用户剪贴板。密码框（SecureTextField）不读。

## 本机验证（macOS）

1. 授予辅助功能后打开 Global Translator，确认设置里「滑词翻译」为开。
2. 配置本地 Ollama 或 DeepSeek（与自动翻译同一套后端）。
3. 在 TextEdit / 备忘录中划选一句英文，松手后应在选区附近看到中文和拷贝按钮。
4. 关闭「滑词翻译」后再划选，不应再出现弹层。
5. 打开 Chrome 且自动翻译 + 扩展桥开启时，页面不应出现 overlay 气泡，但划选仍应弹出滑词译文。
6. `swift test -Xswiftc -warnings-as-errors`
