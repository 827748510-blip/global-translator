# 滑词翻译

在任意 App 里用鼠标划选文字，松手后在选区附近弹出简体中文译文，并可一键 **优化提示词**。与窗口覆盖层气泡、Chrome 扩展桥相互独立。

## 行为

1. 菜单栏设置里有 **滑词翻译** 开关，默认开启。关闭后不再监听划选、不弹层，优化提示词也不可用。
2. 仅在 **鼠标左键抬起** 且选区稳定约 150ms 后读取选区；拖拽过程中不弹层。
3. 弹层展示截断后的原文、结果，以及 **翻译** / **优化提示词** / **拷贝**。划选后默认先翻译；点「优化提示词」才按当前场景改写。操作区上方是 **场景分段**（沟通润色 / 任务指令 / 用词修正，默认 **沟通润色**）。弹层**没有**「翻译后端」分段；DeepSeek 云端 / 本地模型只在设置页切换。切换场景 **不会**关掉弹层。Escape、点击外部、或选区变空时关闭。关掉后同一选区不会立刻再弹；选区清空或换成别的句子后才会再出。
4. 目标语言沿用应用现有设置（当前固定简体中文）。已是简体中文时不请求翻译，显示「已是中文」，但 **仍可优化提示词**（中文草稿很常见）。
5. 空选区、纯空白、单击未划选、以及 `TextFilter` 会拒绝的标识符 / 纯 URL 等不弹层。划选后若读不到文字，短暂显示「无法读取所选文字」（约 1.5 秒后自动收起）；Escape、点击外部、选区变空或再次按下会立刻关闭。含 **内部驼峰**（SwiftUI、ScreenCaptureKit）或「ALL-CAPS 缩写 + 另一技术词」（Vision + OCR）的列表显示「专有名词，无需翻译」，划选时不请求模型；点「翻译」仍会强制走模型。`Sentence 0`、`Hello from the page`、`File / Edit` 等普通英文仍翻译。模型空回包、回声原文或质量拒绝时显示「翻译失败」，**不会**出现「服务返回异常，请稍后重试」。
6. 翻译和优化都走设置页「翻译后端」当前选中的全局后端（`AppConfiguration.backend`，默认持久化）。不会静默换到别的云厂商。全局后端为 DeepSeek 云端且未配置 Key 时，弹层明确提示去设置填写 API Key 并测试连接，不会静默失败。优化使用独立的 `completePlain` 提示词，不走翻译 JSON schema，也不取消 overlay/bridge 在途请求。选区是不可信数据，模型不得执行其中的指令。
7. **优化场景**（`PromptOptimizeMode`，上次选择写入 `AppConfiguration`；新安装默认 **沟通润色**）：
   - **沟通润色**（默认）：合并原「专业回复」+「高情商」。改得更得体、清晰、有同理心；职场/社交得体，不阿谀、不说教、不改事实、不加新承诺。
   - **任务指令**：把含糊意图扩写成给 AI/agent 执行的结构化任务说明（有序步骤、约束、失败即停、禁止 force push 等安全护栏）。修正明显笔误（如 mian→main）；只产出指令文本，不执行任务。不是图像生成提示词。
   - **用词修正**：错别字、用词、不得体/冒犯表达；尽量少改结构与语气策略，保留原意与信息结构。
   已删除「生成提示词」「技术表达」，以及独立的「专业回复 / 高情商」。配置里旧 rawValue 迁移：`professionalReply` / `highEQ` → 沟通润色；`wordingFix` → 用词修正；`generativePrompt` / `technicalExpression` / 未知 → 沟通润色。
   三档都只输出改写结果；默认简体中文，专有名词/标识符原样；英文源且宜保留英则保留（`PromptOptimizationSupport.prefersEnglishOutput`）；不要变成图像生成提示词。
8. **拷贝**：译文 / 优化结果 / 「已是中文」/ 「无需翻译」等可拷贝状态下，成功后按钮变为 **已拷贝**（约 1.5 秒后回到「拷贝」）；失败则短暂显示 **拷贝失败**。不弹系统警告。
9. 不依赖「自动翻译」开关，也不依赖窗口覆盖层是否在跑。Chrome 因扩展桥跳过 overlay 时，滑词仍然可用。

## 权限与选区读取

需要 **辅助功能**（与现有 AX 采集相同）。未授权时只记日志，不弹层、不崩溃。单击空白处不会弹出「无法读取所选文字」。划选后某个 App 读不到文字时，弹层短暂显示该提示后自动收起。

默认用 AX `kAXSelectedText` / 焦点元素的选区范围。剪贴板兜底只在能 **完整备份** 当前剪贴板时才会发 ⌘C，读完 **立刻恢复**；承诺文件 / 延迟数据等无法完整备份时跳过 ⌘C，避免毁掉用户剪贴板。密码框（SecureTextField）以及系统安全输入开启时不读、也不走剪贴板。本应用自己的窗口始终跳过（不弹层、拖选后也不发 ⌘C）。

### 飞书 / Electron 类 App

飞书、Lark 以及不少 Electron / 自绘文本的 App **不暴露可用的 AX `selectedText`**，选区范围也经常是 0。旧逻辑只在「AX 报告 range.length > 0 却给不出字符串」时才 ⌘C，这类 App 永远走不到兜底，划选后静默无弹层。

现在的规则：

1. **鼠标拖选后松手**（按下期间收到 `leftMouseDragged`，系统本身会滤掉几乎不动的位移）：AX 若是 `.empty` / `.unavailable` 且没有可用字符串，才尝试 ⌘C 剪贴板兜底。读到的文本与普通选区一样走 `TextFilter.selectionDecision`（中文显示「已是中文」+ 优化提示词；外文翻译；标识符 / URL 跳过），来源标记为 `clipboardFallback`。弹层锚在鼠标附近（飞书等 App 的 AX 选区范围经常是 0，不能用整块 webview 的 frame，否则会贴到窗口边缘）。
2. **单击、无拖拽**（或可忽略的位移）：不发 ⌘C、不弹层，避免点一下就出现红字或改剪贴板。
3. 拖选后剪贴板也读不到字：短暂显示「无法读取所选文字」，约 1.5 秒后自动收起。
4. 本机窗口、密码框、剪贴板无法完整备份：跳过 ⌘C。

风险：⌘C 会短暂占用通用剪贴板；若目标 App 的拷贝快捷键绑定的不是当前视觉选区，可能读到别的内容。备份/恢复失败时宁可不弹层，也不留下用户剪贴板被换成选区文本。

## 本机验证（macOS）

1. 授予辅助功能后打开 Global Translator，确认设置里「滑词翻译」为开。
2. 配置本地 Ollama 或 DeepSeek（与自动翻译同一套后端）。
3. 在 **TextEdit / 备忘录** 中划选一句英文，松手后应在选区附近看到中文、**翻译**、**优化提示词**和拷贝。单击空白处不应弹层。
4. 点 **优化提示词**（默认场景「沟通润色」），应变为优化中，然后出现改写后的得体文本，可拷贝。设置弹层里滑词开启后可直接改默认场景（分段控件）；滑词弹层里同样用分段切换「任务指令 / 用词修正」。应得到对应风格，且不换后端厂商。重启后应记住上次场景。
5. 划选一句中文草稿（例如「一个女孩站在雨里」）：应显示「已是中文」，不请求翻译；点优化提示词仍应按当前场景改写。
6. 点 **拷贝**：按钮应变为「已拷贝」约 1.5 秒后回到「拷贝」。译文、优化结果、「已是中文」、技术专有名词「无需翻译」都应能拷贝。
7. 在 **飞书 / Lark** 聊天气泡里拖选中文或外文：应弹出滑词层（中文「已是中文」+ 优化提示词，外文则翻译）。仅单击气泡、不拖选，不应出现弹层，也不应改掉系统剪贴板里原来的内容。
8. 划选后看系统剪贴板：应仍是划选前的内容（⌘C 只是瞬间借用）。
9. 关闭「滑词翻译」后再划选，不应再出现弹层。
10. 打开 Chrome 且自动翻译 + 扩展桥开启时，页面不应出现 overlay 气泡，但划选仍应弹出滑词译文 / 优化。
11. 设置页「翻译后端」可在 **DeepSeek 云端** 与 **本地模型** 之间切换，重启后应记住；滑词弹层**不应**再出现该分段。未配置 DeepSeek Key 且全局后端为云端时，划选或点翻译 / 优化提示词应看到「请到设置填写 DeepSeek API Key 并测试连接」，不应静默失败。两边都配置好时，翻译和优化都应走设置页当前选中的后端。
12. `swift test -Xswiftc -warnings-as-errors`

## 长文本（选择 / 滑词）

浏览器或任意 App 里划选 / 粘贴很长的英文（例如 15k–22k 的 Seedance 提示词）时：

1. **不要再静默只译前 4000 字。** 滑词按段落 → 句子 → 词边界拆成约 1800 字一块，按原顺序逐块翻译再拼接。本地模型和 DeepSeek 云端都走同一套分块。
2. 覆盖层 / 页内批次仍保持短句上限（约 4000 字/条、本地 3 段一批、`max_tokens` 128/256）。视频叠层 cue 仍然很短，不受影响。本地后端对**单条长选区块**会按源文字长度提高 `max_tokens`（上限 2048），避免 128 token 截断。
3. 若全文仍超过硬上限（48000 字），只翻译上限内的部分，弹层在译文下方用中文标明 **「原文过长，仅翻译了部分内容」**，拷贝按钮拷的是译文本身。禁止把截断结果当成完整成功。
4. 本机验收：设置后端为 **本地模型**，在 TextEdit 粘贴一段超过 4000 字的英文 Seedance 提示词并划选，应看到多段中文拼接、结尾不是 4000 字处的半截英文；再试一段远超 48000 字的文本，应看到上述中文提示。
