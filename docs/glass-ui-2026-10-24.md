# 毛玻璃 3D 卡片 UI 改造（2026-10-24）

## 目标与边界

把设置页与划词/截图结果弹层改成「3D 卡片 + 毛玻璃」的交互界面，同时**不改功能、信息架构、尺寸计算和点击行为**。不引入依赖，不换技术栈，不做大角度旋转或持续动画。

## 实现

- **最低平台改为 macOS 27**：`Package.swift` 使用 `swift-tools-version: 6.4` + `.macOS(.v27)`；`packaging/Info.plist` 的 `LSMinimumSystemVersion` 同步为 `27.0`，`Doctor` 的判定与文案同步为 macOS 27+，失败/健康测试夹具分别使用 26/27。不再保留 macOS 14–25 的 Material/透光率回退代码。
- **全面使用系统原生 Liquid Glass**：`GTSettingsPanelChrome`、`GTSettingsCard`、`SelectionTranslatePopoverView` 及其操作按钮直接调用 `glassEffect(.regular.interactive(), in: RoundedRectangle(...))`，由系统负责透光、折射和交互反馈。
- **按钮遵循原生 UI 规范**：设置页按钮使用 `glass` 样式；划词动作行使用系统 `HStack` + 每个按钮 `maxWidth/maxHeight` + `glassEffect`，单按钮也能铺满，三个按钮保持等宽。`GTEqualFillButtonStyle` 已删除。曾尝试 `glassProminent`，但其在本机预览中导致内容空白，因此不保留该样式。
- `SettingsPopoverView.swift` + `StatusItemController.swift` + `GTControls.swift`：生产与渲染测试共用 `GTSettingsPanelChrome`，保留原宽度、打开时高度计算、滚动和 outside-click 行为。
- `SelectionTranslatePopoverView.swift`：保留 312 宽、padding、行高、内容测量和窗口定位，不给根视图加额外边距或旋转；翻译按钮的无障碍提示明确「中文译成英文，其他译成简体中文」。
- `SettingsViewModel.swift` / `SettingsSections.swift`：目标语言字段收窄为「窗口/网页目标语言：简体中文」，避免把划词/截图的局部双向能力误写成全局能力；覆盖层和网页桥仍只译简体中文。
- 部署目标提升后，将 `RuntimeContractsTests` 中已过时的 `String(contentsOf:)` 改为 `String(contentsOf:encoding:)`，未改其他业务代码。

## 未覆盖 / 风险

- 最低平台已是 macOS 27，旧系统 Material/透光率回退已删除；`EnvironmentValues.accessibilityReduceTransparency` 仍为只读，系统原生 Reduce Transparency 的实际效果需要人工在系统设置里复测。
- 预览图默认只覆盖设置页顶部与划词长文本态；后端错误、模型展开、权限异常、快捷键冲突等动态状态未逐一手测。
- 截图翻译热键的键盘自动化仍受权限限制，未做完整真实截图链路验收（见 `docs/merged-acceptance-2026-10-24.md`）。
- 本次使用系统原生 Liquid Glass，不是 SceneKit/RealityKit 的立体场景。复杂或高对比桌面背景下仍建议人工确认文字可读性；`glassProminent` 的预览空白问题已通过统一使用普通 `glass` 规避。
