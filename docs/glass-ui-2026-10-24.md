# 毛玻璃 3D 卡片 UI 改造（2026-10-24）

## 目标与边界

把设置页与划词/截图结果弹层改成「3D 卡片 + 毛玻璃」的交互界面，同时**不改功能、信息架构、尺寸计算和点击行为**。不引入依赖，不换技术栈，不做大角度旋转或持续动画。

## 实现

- **macOS 26+ 使用系统原生 Liquid Glass**：`GTSettingsPanelChrome`、`GTSettingsCard`、`SelectionTranslatePopoverView` 都直接调用 `glassEffect(.regular.interactive(), in: RoundedRectangle(...))`，由系统负责透光、折射和交互反馈。API 已按本机 Xcode 27.1 SDK 的 SwiftUICore interface 核实。
- **macOS 14–25 回退**：`GTGlassOptics` / `GTGlassBackground` / `GTRefractionSheen` 仍保留 `ultraThinMaterial` + 材质自身 **72% / 84% / 78% 不透明度**和渐变高光，旧系统也能保持较好的通透感。
- `GTSettingsCard` 的悬停抬升与阴影、`GTRefractionSheen` 的边缘高光只在回退路径使用；原生路径不叠加自绘高光，避免把系统效果盖住。
- Reduce Transparency 时回退层移除高光并使用实色；原生效果由系统处理可访问性设置。
- `SettingsPopoverView.swift` + `StatusItemController.swift` + `GTControls.swift`
  - 内层不再用不透明背景遮住玻璃；生产与渲染测试共用 `GTSettingsPanelChrome`（`regularMaterial` + 极淡顶部渐变 + 圆角描边），保留原宽度、打开时高度计算、滚动和 outside-click 行为。
- `SelectionTranslatePopoverView.swift`
  - 背景改为共享玻璃表面，配渐变描边；保留 312 宽、padding、行高、内容测量和窗口定位，不给根视图加额外边距或旋转；翻译按钮的无障碍提示明确「中文译成英文，其他译成简体中文」。
- `SettingsViewModel.swift` / `SettingsSections.swift`
  - 目标语言字段收窄为「窗口/网页目标语言：简体中文」，避免把划词/截图的局部双向能力误写成全局能力；覆盖层和网页桥仍只译简体中文。

## 验证

- `swift test -Xswiftc -warnings-as-errors`：**552 tests / 53 suites 全绿**（一次全量并行下截图 suite 超时，单独复跑及全量复跑均通过，为既有负载敏感抖动）。
- `swift build -c release -Xswiftc -warnings-as-errors` 与 `scripts/package-app.sh` 通过。
- 新增 `GlassUIRenderTests`：
  - 设置整页 `NSHostingView` 渲染（浅色、深色、彩色桌面背景），使用生产同款 `GTSettingsPanelChrome`；
  - 单张玻璃卡渲染；
  - 划词弹层长原文 + 长译文 + 保存路径渲染，比较实际 `fittingHeight` 与 `contentSize`（±12pt 文字测量容差），并保留 `panelFrame` 断言；
  - 划词弹层在彩色背景下渲染，直接观察透光；
  - `GTGlassBackground.usesMaterial` 直接覆盖 Reduce Transparency 两个分支选择。
- 人工查看导出的预览图：卡片边界清楚，文字无裁切，保存路径完整显示；深色模式文字对比正常；**彩色背景可透过面板与划词卡片**，不是不透明的磨砂白。
- 新版已安装到 `/Applications` 与 `~/Applications`，启动与打开设置页烟测通过。
- 两轮独立 UI 复核通过；已修正目标语言范围、生产根层预览覆盖和尺寸断言名实不符问题。

## 未覆盖 / 风险

- Reduce Transparency 的实色降级在代码中逐层实现（根面板 / 设置卡 / 划词卡），当前 Swift 工具链的 `EnvironmentValues.accessibilityReduceTransparency` 为只读，未做该开关的渲染截图验证；需要人工在系统设置里复测。
- 预览图默认只覆盖设置页顶部与划词长文本态；后端错误、模型展开、权限异常、快捷键冲突等动态状态未逐一手测。
- 截图翻译热键的键盘自动化仍受权限限制，未做完整真实截图链路验收（见 `docs/merged-acceptance-2026-10-24.md`）。
- 本次「3D」在 macOS 26+ 上是系统原生 Liquid Glass；旧系统回退是 Material + 真实透光率 + 边缘高光 + 阴影 + 悬停抬升，不是 SceneKit/RealityKit 的立体场景。复杂或高对比桌面背景下仍建议人工确认文字可读性。
